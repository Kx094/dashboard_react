## Next.js App Router Course - Starter

This is the final result of the coursework project to learn the basics off the Next.js framework building a full stack Web App, in this project I built a financial dashboard with

* A home page
* A login page
* Dashboard pages protected with authentication
* The functions to add, edit, and delte invoices

All being stored and protected with a database

This is the starter template for the Next.js App Router Course. It contains the starting code for the dashboard application.
